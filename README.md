## Instructions
- Open `index.html` and allow camera access
- Stand in front of the camera and move to interact with the work
- Small movements trigger scanning visuals, larger movements trigger a locked state
- `↑ / ↓` adjust sensitivity, `S` saves a screenshot, `V` shows/hides the preview, `C` clears the screen

## About
Residual Body is a creative coding project using a camera and motion detection.  
It explores how the body is seen by a machine, turning movement into scanning, tracking, and signal-based visuals.
